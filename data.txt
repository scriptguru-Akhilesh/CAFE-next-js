CORNER ROASTERY - API DATA CONTRACT & INITIAL SEED DATA
================================================================================
This file contains the complete specification of all API data structures,
mock responses, schema formats, and seed data. You can easily copy and connect
these data definitions to any custom backend database (PostgreSQL, Supabase, 
MongoDB, Firebase) or external REST API service.

================================================================================
1. ADMIN AUTHENTICATION API
================================================================================

Endpoint: POST /api/auth/login
Description: Authenticates owner/admin using email/username and password.

Request Body:
{
  "email": "admin@cornerroastery.com", // or username "admin"
  "password": "admin123"
}

Success Response (200 OK):
{
  "success": true,
  "user": {
    "id": "admin-1",
    "name": "Cafe Owner",
    "email": "admin@cornerroastery.com",
    "role": "admin"
  },
  "token": "token_admin_corner_roastery_session"
}

Error Response (401 Unauthorized):
{
  "success": false,
  "error": "Invalid email or password. Default is admin@cornerroastery.com / admin123"
}

--------------------------------------------------------------------------------
Endpoint: GET /api/auth/session
Description: Verifies active admin session token.

Headers:
Authorization: Bearer <token>

Response (200 OK):
{
  "authenticated": true,
  "user": {
    "id": "admin-1",
    "name": "Cafe Owner",
    "email": "admin@cornerroastery.com",
    "role": "admin"
  }
}

4. ORDERS & KITCHEN DISPLAY SYSTEM (KDS) API
================================================================================

Endpoint: GET /api/orders
Description: Returns list of live orders.

Response (200 OK):
[
  {
    "id": "ORD-101",
    "tableNumber": "5",
    "items": [
      {
        "id": "item-1",
        "name": "Espresso Roast",
        "price": 180,
        "quantity": 2,
        "notes": "Extra hot please"
      },
      {
        "id": "item-6",
        "name": "Butter Croissant",
        "price": 190,
        "quantity": 1
      }
    ],
    "totalAmount": 550,
    "status": "In Progress", // Allowed values: "Pending" | "In Progress" | "Ready" | "Served" | "Cancelled"
    "createdAt": 1710000050000,
    "notes": "Table 5 priority"
  }
]

--------------------------------------------------------------------------------
Endpoint: POST /api/orders
Description: Place a new customer order from digital menu.

Request Body:
{
  "tableNumber": "5",
  "items": [
    {
      "id": "item-2",
      "name": "Cappuccino Artisan",
      "price": 240,
      "quantity": 1,
      "notes": "Oat milk"
    }
  ],
  "totalAmount": 240,
  "notes": "Corner seat"
}

Response (201 Created):
{
  "success": true,
  "order": {
    "id": "ORD-102",
    "tableNumber": "5",
    "items": [...],
    "totalAmount": 240,
    "status": "Pending",
    "createdAt": 1710000060000
  }
}

--------------------------------------------------------------------------------
Endpoint: PATCH /api/orders/:id
Description: Update order status from Kitchen Display.

Request Body:
{
  "status": "Ready" // or "In Progress", "Served", "Cancelled"
}

Response (200 OK):
{
  "success": true,
  "order": {
    "id": "ORD-102",
    "status": "Ready"
  }
}
